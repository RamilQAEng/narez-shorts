# НАРЕЗ — нарезка длинных видео в шортсы на своём компьютере

Кидаешь ссылку на стрим, фильм или подкаст — получаешь пачку вертикальных клипов 9:16
с субтитрами, хуком и своим баннером. Сильные моменты выбирает твой ИИ-агент
(Claude Code или Codex) по подписке, которая у тебя уже есть. Платные API-ключи не нужны,
всё считается у тебя на ПК в Docker.

[English README](README.en.md)

## Как это работает

```
ссылка или файл → скачивание → текст (слова с таймкодами) → ИИ-агент выбирает моменты
→ нарезка 15–60 с и кадр 9:16 с лицом в центре → субтитры, хук, баннер
```

На нашем тесте: 23-минутный русскоязычный стрим → 6 готовых клипов.

## Что мы доработали

Основа — открытый проект OpenShorts (MIT). Сверху добавлено:

| Что | Зачем | Где в коде |
|---|---|---|
| **Режим агента** (`AGENT_CLIPS=1`) | Моменты и хуки выбирает твой Claude Code или Codex: система кладёт `transcript.json` в папку задачи и ждёт `clips.json`. Ключ Gemini и окно «нужны ключи» в этом режиме не нужны | `main.py`, `app.py` (`AGENT_CLIPS`, `/api/config.agentClips`), `dashboard/src/App.jsx` |
| **Нарезка из готового списка** | `--clips clips.json` и `--transcribe-only` для командной строки и агентов | `main.py` |
| **Баннер бренда** | Картинка, GIF или видео (канал Telegram, реклама VPN, свой бренд) на каждом клипе, сверху или снизу | `brand_banner.py`, `brand_api.py`, `BannerPicker.jsx` |
| **Проекты для стримов** | Рамка игры и рамка вебки: игра сверху, автор снизу, крупный план в сильные моменты (`zoom_moments`) | `projects.py`, `project_layout.py`, `ProjectPicker.jsx`, `FrameBoxEditor.jsx` |
| **Субтитры на кириллице** | Montserrat ExtraBold с размером под вертикальный кадр (Anton не умеет кириллицу) | `subtitles.py` |
| **Повтор коротких нарезок** | Если ffmpeg вырезал меньше 80% нужной длины, кусок режется заново | `ffmpeg_utils.py` |
| **Куки YouTube из файла** | `YOUTUBE_COOKIES` может быть путём к `cookies.txt`; `refresh_cookies.ps1` обновляет его из Firefox каждые 5 минут | `yt_account.py`, `refresh_cookies.ps1` |
| **Запуск в одну команду** | `start.ps1`: настройки, куки, нужные контейнеры, адрес интерфейса | `start.ps1`, `docker-compose.override.example.yml` |

## Что нужно

| | Минимум | Комфортно |
|---|---|---|
| Система | Windows 10/11 64-бит, macOS или Linux | Windows 11 |
| Память | 8 ГБ | 16 ГБ |
| Диск | ~20 ГБ (образ бэкенда около 6 ГБ) | SSD |
| Видеокарта | не нужна | NVIDIA: расшифровка в разы быстрее |
| Программы | Docker Desktop, Git | Firefox — для куки YouTube |
| ИИ-агент | Claude Code или Codex с подпиской | — |

Без видеокарты расшифровка идёт примерно в реальном времени: 23 минуты видео ≈ 20 минут.

## Установка

### Вариант 1. Пусть поставит агент

Склонируй репозиторий, открой терминал в его папке, запусти `claude` или `codex` и напиши:

```
Прочитай INSTALL_AGENT.md и установи НАРЕЗ на этот компьютер.
```

Агент проверит Docker, Firefox и всё остальное, спросит перед установкой программ и запустит систему.

### Вариант 2. Руками (Windows)

1. Включена виртуализация (Диспетчер задач → Производительность → ЦП → «Виртуализация: Включено»).
2. Установи [Docker Desktop](https://www.docker.com/products/docker-desktop/) с WSL 2, перезагрузи ПК, дождись «Engine running».
3. Установи Firefox и [uv](https://docs.astral.sh/uv/) (`winget install astral-sh.uv`) — для куки YouTube.
4. Склонируй репозиторий и запусти в его папке:
   ```powershell
   .\start.ps1
   ```
   Первый запуск собирает образы: 20–40 минут и несколько гигабайт. Потом — секунды.
5. Открой http://localhost:5175

На macOS и Linux: `cp docker-compose.override.example.yml docker-compose.override.yml`,
затем `docker compose up -d backend frontend`.

## Как резать

1. В интерфейсе вставь ссылку или загрузи файл, выбери 9:16, при желании проект и баннер, запусти.
2. Когда задача ждёт агента, открой терминал в папке репозитория и скажи агенту:
   ```
   Нарежь последний стрим: прочитай transcript.json в последней задаче в output/
   и запиши рядом clips.json по формату из README.
   ```
3. Клипы появятся в галерее и в `output/<задача>/`.

Формат `clips.json`:

```json
{
  "shorts": [
    {
      "start": 760.4,
      "end": 801.9,
      "video_title_for_youtube_short": "Чат не поверил, что это сработало",
      "viral_hook_text": "Чат не поверил",
      "video_description_for_tiktok": "…",
      "video_description_for_instagram": "…",
      "zoom_moments": [[781.0, 785.5]]
    }
  ]
}
```

`start` и `end` — секунды исходного видео, внутри его длины. Описания и `zoom_moments`
(только для проектов) — по желанию. Задача ждёт `clips.json` до 2 часов (`AGENT_CLIPS_WAIT_MIN`).

## Куки YouTube и ключи

- **Только Firefox.** Chrome, Edge и Яндекс Браузер на Windows шифруют куки так, что yt-dlp их не читает.
- **Отдельный аккаунт Google** для скачивания, не основной: YouTube может ограничить аккаунт за частые скачивания.
- `yt_cookies.txt` — это доступ к аккаунту. Он в `.gitignore`, никому его не отправляй.
- Если YouTube всё равно не отдаёт видео — скачай его сам и загрузи файлом.
- **Ключи не нужны** в режиме агента. Gemini, Upload-Post, ElevenLabs, fal — только для дополнительных функций
  (AI-эффекты, автопостинг, озвучка, обложки). Если программа просит ключ — режим агента выключен:
  проверь, что есть `docker-compose.override.yml` с `AGENT_CLIPS=1`, и перезапусти `start.ps1`.

## Видеокарта NVIDIA

Раскомментируй блок GPU в `docker-compose.override.yml`, добавь в `.env`:

```
WHISPER_MODEL=large-v3-turbo
WHISPER_DEVICE=cuda
WHISPER_COMPUTE=float16
FFMPEG_ENCODER=auto
```

и пересобери: `docker compose up -d --build backend frontend`. На Windows нужен Docker Desktop на WSL 2 и свежий драйвер NVIDIA.

## Обновление

```powershell
git pull
docker compose up -d --build backend frontend
```

Клипы, баннеры (`brand/`) и проекты (`projects/`) при обновлении остаются на месте.

## Права и ограничения

- За права на видео отвечаешь ты: режь своё, ролики с разрешения автора или по клип-программам.
- Лимиты подписки Claude или Codex задаёт провайдер; длинный стрим — несколько запросов к агенту.
